# 画布 AI 文生图

画布底部的加号按钮点击后显示「添加素材」和「文生图」。「添加素材」继续打开原有图片导入对话框；「文生图」立即在当前视口中心创建空白图片占位节点，不发送生成请求。

选中占位图后，节点下方显示多行提示词输入框。「生成设置」可选择智能比例、1:1、2:3、3:2、3:4、4:3、9:16、16:9，以及 1K、1.5K、2K 分辨率。默认智能比例 / 2K。Enter 换行，⌘/Ctrl + Enter 或提交按钮生成；中文输入法确认不会触发提交。提示词去空白后最多 4000 个字符。模型仍由后端固定，设置结构可继续扩展模型选择。

提示词与参数保存在图片 shape 的 `meta.imageGeneration` 中，随项目保存。正在执行的请求仅保存在当前会话中，不写入快照，因此重开项目或撤销生成后，占位图可继续编辑，不会永远显示生成中。

生成通过 Tauri command `generate_image` 调用火山方舟 Seedream 5.0 Pro。前端发送提示词、分辨率和 `aspectRatio`，Rust 端读取启动时的 `ARK_API_KEY`，请求 `doubao-seedream-5-0-pro-260628`，固定单张 PNG。智能比例保留 Ark 的尺寸档位；固定比例转换为相应像素预算、8 像素对齐的 `WIDTHxHEIGHT`，因此比例实际参与生成。省略比例的旧请求仍兼容智能比例。

生成期间节点显示 Grainient 动效，并隐藏提示词面板。同一节点重复提交会被忽略。成功后经 `ProjectAssetStore` 保存原图及预览，原位更新现有 image shape 并移除生图元数据，保留节点 ID、当前位置、旋转和图层顺序；图片等比适配占位范围。结果是普通图片节点，可裁剪、调整、导出，不再显示提示词面板。撤销会恢复可编辑的占位图，重做恢复生成结果。

失败会保留节点及提示词，选中后可修改重试。删除节点（包括删除后撤销）、切换页面、锁定、只读或关闭画布后，异步结果不会插入错误的画布。不会自动重试收费请求。

开发环境可在项目根目录 `.env` 中设置 `ARK_API_KEY`；生产环境应在启动桌面应用前注入同名环境变量。Rust 回归测试使用本地模拟 HTTP 服务，不调用真实 Ark。浏览器集成回归入口为 `/tests/image-generation.html`，交互预览为 `/tests/image-generation.html?manual`；两者都使用模拟 IPC，不消耗额度。
