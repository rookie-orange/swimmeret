# 画布 AI 文生图

画布底部的「AI 生图」输入框使用 Tauri command `generate_image` 调用火山方舟 Seedream 5.0 Pro。前端只发送提示词和尺寸，Rust 端读取启动时的 `ARK_API_KEY`，请求 `doubao-seedream-5-0-pro-260628`，固定要求单张 PNG，并立即下载 Ark 返回的临时 URL（URL 只保留 24 小时）。

默认尺寸是 `2K`，可用尺寸为 `1K`、`1.5K`、`2K`。提示词会在前后端分别去空白并限制为 4000 个字符。返回的 PNG 先通过现有 `ProjectAssetStore` 保存原图和预览，再创建一个可选中的图片 shape，因此项目自动保存、撤销/重做和后续导出都使用同一套项目素材链路。

生成期间输入框会禁用，重复提交会被忽略。网络、模型响应、下载或本地素材写入失败时会在画布上显示错误并保留提示词，方便修改后重试。切换页面、关闭画布或进入只读状态后，已完成的异步结果不会插入错误的画布。

开发环境可以在项目根目录 `.env` 中设置 `ARK_API_KEY`；生产环境应在启动桌面应用前注入同名环境变量。接口和响应解析的回归测试位于 `src-tauri/src/clients/ark.rs`，使用本地模拟 HTTP 服务，不会调用真实 Ark 或消耗额度。
